The Problem & The Story

The Mystery of the Ghost Service & The 200/CHDIR Crash Loop

On a production Ubuntu VPS, you manage multiple micro-services. For example, appointment.keshavsoft.com is reverse-proxied by Caddy to internal port 3000, and managed by a native systemd unit: /etc/systemd/system/appointment.keshavsoft.com.service.

Everything runs smoothly — until one day, during development or maintenance, you rename the physical directory: from /root/KeshavSoft/appointment-notifier to appointment-notifier-v1.

The Silent Cascade Failure (status=200/CHDIR)

1. The service file still exists in /etc/systemd/system/.
2. Caddy still routes traffic from appointment.keshavsoft.com to localhost:3000.
3. But when systemd tries to launch Node.js, it attempts to cd into WorkingDirectory. Because the folder was renamed, systemd fails with:
Process: 2100 ExecStart=... (code=exited, status=200/CHDIR)
4. Because of Restart=on-failure, systemd enters an infinite, silent restart loop.
5. Nothing is listening on port 3000, and Caddy returns 502 Bad Gateway!

Why Traditional Tools Fail Here: Standard inspection tools only read the unit text or live sockets. Because the folder was renamed, the .env file was unreadable, and no socket was listening. Port 3000 vanished into thin air!

The Solution: ubuntu-services is the physical folder auditor. It opens every systemd unit and tests whether fs.existsSync(WorkingDirectory) is true. If the folder is missing, it immediately flags it as ❌ MISSING FOLDER and alerts you to the exact directory that broke!

2. Port Lookup ubuntu-service-port

Reverse-lookup from port number to owning service unit, PID, and GitHub repo.

Verifies the physical working directory on disk to eliminate ghost services & 200/CHDIR errors.

Command Reference

CLI Commands & Flags

Command Purpose Example
npx ubuntu-services Prints overview table verifying physical directories on disk npx usv
broken / doctor / missing Isolates broken units, missing folders, or crash loops npx ubuntu-services broken
dirs Discovers all systemd service directories on Ubuntu npx ubuntu-services dirs
inspect <name> Deeply inspects raw unit sections, health, and port npx ubuntu-services inspect appointment.keshavsoft.com
--json Outputs machine-readable JSON for monitoring or CI/CD npx ubuntu-services --json
